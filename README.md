## 🧭 How I work

- **Evidence before claims.** Tests and measurements, not promises.
- **Secure by default.** Least privilege, secrets kept out of code, and risky actions behind an approval.
- **Small, reviewable changes** with clear documentation and reproducible tests.
- **Public-safe engineering.** Clean-room work that's safe to share.

Building practical cloud-native and AI-assisted tools for safer modernization, delivery and operations.
